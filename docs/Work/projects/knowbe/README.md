# KnowBe

社会福祉領域の案件で得た経験・判断・学びを、自分の知見として整理するための個人用ログ。

> 機密情報、顧客情報、社内限定URL、ソースコード、認証情報などは記載しない。

## Structure

- `Daily/` — 日々の作業・理解・詰まり・振り返り
- `ADR/` — 技術的な判断と、その背景・選択肢・結果
- `Notes/` — 案件固有のメモや整理途中の内容
- `Knowledge/` — KnowBe案件で得た再利用可能な知見

## Rule

- Dailyはラフに残す
- 再利用できる学びはKnowledgeへ整理する
- 意思決定の背景を残す価値があるものはADRへ切り出す
- 案件固有情報は抽象化・匿名化して記録する
